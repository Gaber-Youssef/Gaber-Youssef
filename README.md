## What I build

- **Agentic workflow systems** — multi-agent orchestration with tools, MCP, memory, human checkpoints and guardrails, for multi-step knowledge work a chatbot can't finish.
- **RAG and grounded knowledge products** — ingestion, hybrid search, reranking, permissions, citations and retrieval evaluation over private data.
- **LLM platforms and LLMOps** — model gateways, tracing, offline and online evals, and cost and latency controls.
- **Production rescue** — auditing AI prototypes that work in demos but fail in production, then simplifying and shipping a reliable version.
- **Real-time computer vision** — detection, tracking, pose and gaze estimation on live video, when the problem calls for it.

## Selected work

- **Agentic data-analysis platform (Snowheap)** — architected the multi-agent version of a canvas-based platform where non-AI teams build their own analysis pipelines: RAG, tool access, web search, persistent memory and telemetry. Multi-agent report generation in production with Fortune-500 companies.
- **Grounded conversational AI (MarketScale)** — a retrieval layer over channel content, transcripts and brand context, with hybrid search, reranking and retrieval evaluation, plus multi-agent content workflows with streamed progress.
- **Real-time proctoring platform (Rosalyn.ai)** — microservices AI platform with gaze, pose and object detection on Kafka, FastAPI, Elasticsearch and Kubernetes.
- **Live sports analysis (FX1 Sports)** — real-time MMA stream analysis that detects strikes and takedowns, deployed on Google Cloud.

Most of this work is private client code. Write-ups and case studies are on **[my blog](https://gaberyoussef.dev/blog/)**.
